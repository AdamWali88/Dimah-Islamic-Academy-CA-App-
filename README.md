# Dimah Academy Islamic Continuous Assessment App — V44

Arabic-first adaptation of the approved Umar Idris CA App V39 codebase, with the Dimah Academy identity and logo.

## GitHub Pages
1. Extract this ZIP.
2. Upload every file directly to the root of a separate GitHub repository.
3. Confirm `index.html` is at the repository root.
4. Enable Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Classes and sections
Class levels: Islamic Primary 1–6, JISS 1–3, SISS 1–3. The section/arm selector uses Arabic labels: إسلامية, متوسط, ثانوية.

The app retains the V39 assessment, student, question bank, terminal examination, print/export and offline features. It is designed for offline use after the app shell has loaded once over HTTPS.
